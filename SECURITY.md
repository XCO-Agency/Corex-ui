# Security policy

## Supported versions

Security fixes go out as a normal `@xco-agency/corex-ui` release on the current 2.x line. Older majors are not maintained.

## Reporting a vulnerability

Please report a vulnerability privately through [GitHub Security Advisories](https://github.com/XCO-Agency/Corex-ui/security/advisories/new).

Do not open a public issue, pull request, or discussion for an unfixed vulnerability. Include a description, the version you tested, and a way to reproduce the problem if you have one.

We will acknowledge the report, work on a fix, and publish it with a changelog entry and a `vX.Y.Z` release. See [docs/releasing.md](docs/releasing.md) for how that release is cut.
