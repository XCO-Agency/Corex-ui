# Avatar

Thin wrapper over `s-avatar`.

```tsx
import { Avatar } from "@xco-agency/corex-ui";

<Avatar name="Ada Lovelace" initials="AL" />;
```

## Prop mapping

| Legacy prop                          | Behavior                 |
| ------------------------------------ | ------------------------ |
| `name`, `initials`, `source`, `size` | Passed straight through. |
