# Thumbnail

Thin wrapper over `s-thumbnail`.

```tsx
import { Thumbnail } from "@xco/corex-ui";

<Thumbnail source="https://example.com/product.png" alt="Product photo" />;
```

## Prop mapping

| Legacy prop             | Behavior                 |
| ----------------------- | ------------------------ |
| `source`, `alt`, `size` | Passed straight through. |
